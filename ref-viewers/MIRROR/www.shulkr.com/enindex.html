Schematics 101

What is a Minecraft schematic?

A schematic is a saved copy of a build: every block, its position and its state, packed into one file. Load it into a world and the build appears exactly as it was made, ready to paste in creative or to follow block by block in survival. Each tool saves its own format, and shulkr opens all of them.

How to use a schematic

Litematica (Java)

.litematic
  1. Put the file in the schematics folder inside your .minecraft directory.
  2. In game, press M, choose Load Schematics, select the file and click Load Schematic.
  3. Move the placement where you want it, then build along the overlay or switch on Easy Place.

WorldEdit (Java)

.schem
  1. Put the file in config/worldedit/schematics, or plugins/WorldEdit/schematics on a server.
  2. Run //schem load followed by the file name.
  3. Stand where the build should go and run //paste.

Structure block (Bedrock)

.mcstructure
  1. With cheats on, run /give @s structure_block and set the block to Load mode.
  2. Click Import and pick the .mcstructure file. Holding a Java file? Convert it first.
  3. Adjust the offset, then press Load to place the build.

Free Minecraft schematics for every kind of build

Every schematic on shulkr is free to download and comes with a 3D preview, so you can walk around a build before it touches your world. The catalog is shared by the community and covers survival bases, redstone machines, decorations and whole landscapes, each tagged by category and size.

Most players come for farm schematics: iron farms, villager trading halls and crop farms that quote their output per hour. House schematics run from starter cottages to mansions, redstone schematics cover doors, cannons and sorting systems, and castle schematics take on the big medieval projects.

Each build downloads in the format your tool reads: .litematic for Litematica, .schem for WorldEdit, .nbt for Create and vanilla structure blocks, and .mcstructure for Bedrock Edition. Java and Bedrock builds live side by side, and the converter moves any schematic between editions right in your browser.

Built something worth sharing? Upload your schematic and it gets its own page with a 3D preview, a material list and download counts.
